# Практическая работа № 2

**Тема:** «Объявление класса, создание экземпляров класса»
**Тема программы:** 1.2 «Классы и объекты в языке Python»

Все 20 заданий (обязательные 1–18 и задания повышенной сложности
19–20) выполнены на Python в одном модуле `main.py`.

## Состав папки

| Файл / папка | Назначение |
|---|---|
| `main.py` | исходный код всех заданий 1–20, оформлен по PEP 8 |
| `Отчет_ПР2.docx` | готовый отчёт: титульный лист, теория, код каждого задания, изображения результатов, ответы на контрольные вопросы, вывод |
| `вывод/task_01.txt … task_20.txt` | консольный вывод каждого задания (UTF-8) |
| `скриншоты/task_01.png … task_20.png` | изображения результатов запуска |
| `output.txt` | полный вывод всех заданий подряд |

## Запуск

Требуется Python 3.10 или новее, сторонние библиотеки не нужны.

```
python main.py        # выполнить все задания 1–20
python main.py 7      # выполнить только задание 7
```

Каждое задание в `main.py` отделено комментарием с номером, у каждого
класса есть docstring, демонстрационные функции названы `task_01` …
`task_20`.

## Перед сдачей

1. На титульном листе `Отчет_ПР2.docx` впишите фамилию, имя, группу и
   дату.
2. Изображения в папке `скриншоты` построены из фактического вывода
   программы. При необходимости замените их собственными снимками
   экрана (запуск `python main.py <номер>`) и обновите рисунки в
   отчёте.
3. Проверьте требования преподавателя к печатной форме отчёта.

## Особенности реализации

- **Задание 8.** Класс `PointCounter` — это `Point` из задания 1,
  дополненный атрибутом класса `count_points`. Отдельное имя выбрано,
  чтобы не перекрывать класс `Point` первого задания.
- **Задание 11.** Класс `TemperatureV2` — переработанная версия
  `Temperature` из задания 10: состояние приватное, `celsius` доступен
  только для чтения, `fahrenheit` — двустороннее свойство.
- **Задание 11, важный нюанс.** Присваивание `t.__celsius = 100` вне
  тела класса не изменяет состояние объекта: name mangling действует
  только внутри класса, поэтому создаётся посторонний атрибут с именем
  `__celsius`. Настоящее значение хранится в `_TemperatureV2__celsius`.
  В демонстрации это показано отдельно.
- **Задание 20.** Реестр хранит слабые ссылки (`weakref`): если хранить
  в списке класса сами объекты, они никогда не будут удалены, пока жив
  реестр, и `__del__` не сработает. Переменная цикла `obj` тоже является
  ссылкой, поэтому перед удалением она обнуляется.

## Проверка

```
python -m py_compile main.py
python main.py
```

Все задания выполняются без ошибок; некорректные данные (возраст 150,
отрицательные суммы, превышение остатка, неверные типы в инвентаре)
обрабатываются через `try/except` и выводятся в консоль.
